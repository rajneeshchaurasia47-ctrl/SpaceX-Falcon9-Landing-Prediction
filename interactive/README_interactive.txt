SpaceX Capstone - Interactive Map and Dashboard

1. Extract the ZIP to a folder.
2. Open PowerShell in that folder.
3. Install packages for your user account:
   python -m pip install --user -r requirements_interactive.txt
4. Run:
   python build_spacex_interactive.py
5. Open http://127.0.0.1:8050 in your browser.
6. Open interactive_outputs/launch_sites_map.html for the Folium map.
7. Open interactive_outputs/site_success_interactive.html for an offline Plotly chart.
8. Press Ctrl+C in PowerShell to stop the dashboard.

This is a project component, not a completed Coursera submission.
